# ADR-0010 — Serialization

**Status:** Proposed — Decision Pending Review

Evaluate Protocol Buffers, CBOR, MessagePack, FlatBuffers when justified, and custom binary only as an exceptional path against wire size, performance, evolution, schema validation, Android/Kotlin support, interoperability, and auditability.

No serialization format is approved by this draft.
