# ARCH-005 — ADR Framework

**Status:** Proposed

ADR lifecycle: Proposed → review → approval → Accepted → implementation through linked Issues → Deprecated/Superseded.

ADR = decision. Issue = implementation, verification, migration, or follow-up.

Required ADR fields: status, date, deciders, context, decision, consequences, alternatives, relationships, approval evidence, linked Issues.

Requires: ARCH-001 and accepted ADR-0007.
