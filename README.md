# Eagle

Eagle — منصة مراسلات متعددة المنصات تركز على الأمن والخصوصية والأداء والاستقرار.

## الهدف

Android + iOS + Desktop، مع P2P أولًا، وبدون اعتماد وقت التشغيل على خدمة طرف ثالث لتخزين الرسائل أو فرض الثقة.

## Security First

الأمن ليس مرحلة بعد التطوير. الهوية، المفاتيح، البروتوكول، التخزين، النقل، البناء، والإصدار كلها تحت بوابات أمنية قابلة للتحقق.
