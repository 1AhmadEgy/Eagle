# خط أساس الأمن — Eagle

## قواعد إلزامية
- ممنوع تخزين API keys أو tokens أو كلمات المرور أو شهادات خاصة في المستودع.
- استخدام متغيرات بيئة/Secret Manager مناسب للتشغيل.
- مراجعة الصلاحيات وفق مبدأ أقل صلاحية.
- حماية main ومنع العمل المباشر عليه كمسار اعتيادي.
- فحص الاعتماديات بحثًا عن الثغرات والتغييرات غير المتوقعة.
- SAST وlint وtests ضمن CI عند توفر المشروع البرمجي.
- التحقق من المدخلات ومخرجات الخدمات.
- مصادقة وتفويض صريحان لكل واجهة حساسة.
- سجلات التدقيق لا تحتوي أسرارًا أو بيانات شخصية غير لازمة.
- النسخ الاحتياطية وخطة الاستعادة جزء من التصميم.

## بوابة الأمن قبل الدمج
1. لا أسرار.
2. لا ثغرات حرجة غير معالجة.
3. الاختبارات المطلوبة ناجحة.
4. التبعيات مقيدة ومراجعة.
5. تغييرات الصلاحيات موثقة.
6. التغييرات الحساسة لها مراجعة بشرية.

## ملاحظة
هذه baseline وليست شهادة أمن أو ضمانًا مطلقًا. يجب تخصيصها بعد معرفة طبيعة النظام وبياناته وبيئة التشغيل.
