## الغرض
هذا المستند هو نقطة الدخول المرجعية للمشروع. يجمع القرارات المعتمدة، نطاق التوثيق، حالة التحقق، قواعد العمل، وروابط المستندات الأخرى.

## المستودع المركزي
- GitHub: 1AhmadEgy/Eagle
- الفرع الافتراضي المتحقق: main
- حالة المستودع وقت التوثيق: عام وغير مؤرشف.
- يجب اعتبار main خط الإصدار/الدمج، وليس مساحة العمل اليومية.

## مبادئ المشروع
1. الأمن أولًا.
2. الاعتماد على مشاريع ومكتبات وأدوات وأبحاث جاهزة ومختبرة متى كان ذلك مناسبًا.
3. كل قرار مهم يجب أن يكون قابلًا للتتبع إلى متطلب أو مصدر أو قرار معماري.
4. لا تُعتبر معلومة غير متحققة حقيقة تنفيذية.
5. لا تُرفع أسرار أو مفاتيح أو بيانات حساسة إلى Git.
6. التغييرات تمر عبر فرع وPR ومراجعة واختبارات قبل الدمج.
7. الوثائق جزء من المنتج وليست مادة ثانوية.

## حالة المرجع
