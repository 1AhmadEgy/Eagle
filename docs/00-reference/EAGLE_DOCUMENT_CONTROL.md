# Eagle Document Control & Public Readability

## الغرض

منع الفوضى بين الوثائق التاريخية والوثائق المعتمدة مع إبقاء المشروع قابلًا للقراءة العامة.

## الحقول الإلزامية

Document ID، العنوان، الحالة، الإصدار، تاريخ آخر تحديث، المالك، النطاق، المراجع، حالة الأدلة، وعلاقات REQ/ADR/TEST عند الحاجة.

## حالات الوثائق

| الحالة | المعنى |
|---|---|
| PROPOSED | اقتراح |
| REVIEWED | تمت مراجعته |
| APPROVED | مرجع معتمد |
| HISTORICAL | سجل تاريخي |
| SUPERSEDED | استبدله مرجع أحدث |
| DEPRECATED | لم يعد للاستخدام |
| BLOCKED | يمنع الاعتماد |

## Canonical marker

الوثيقة canonical فقط عند وجود قرار اعتماد واضح، وعدم التعارض مع مصدر أحدث، وإمكان ربطها بالعقود والتنفيذ أو القصد المعماري، ووجود provenance واضح.

## الحفاظ على التاريخ

لا نحذف التاريخ لتجميل السجل. النسخة التاريخية تحفظ في archive، والنسخة الحالية تربط بها.

## Public readability

أي شخص يدخل المستودع يجب أن يستطيع فهم:
- ما المشروع؟
- كيف يعمل؟
- ما حدود الأمن؟
- أين الكود؟
- كيف يختبر؟
- كيف يعتمد؟
- كيف يصدر؟
- ما الذي لم يكتمل؟

## الأسرار

أي secret أو بيانات شخصية حقيقية أو artifact حساس خارج التوثيق العام.

## الرسومات

تستخدم Mermaid أو ASCII عند الحاجة، مع شرح نصي للمعنى.
