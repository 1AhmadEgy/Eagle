## ADR rule

An ADR records a decision.

A GitHub Issue records implementation, verification, migration, or follow-up work.

Example:

- ADR-0010 decides the serialization format.
- PROTO-003 implements the accepted serialization decision.

## Acceptance rule

An ADR marked Proposed is not an approved technical choice.

Where an ADR conflicts with an earlier approved record, the conflict must be explicitly reconciled and recorded rather than silently overriding the earlier decision.
