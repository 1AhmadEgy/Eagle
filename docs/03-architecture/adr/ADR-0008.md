# ADR-0008 — Cryptographic Protocol

**Status:** Proposed — Decision Pending Review  
**Date:** 2026-10-02  
**Related ADR:** ADR-0007

## Context
Eagle requires end-to-end encrypted messaging over asynchronous and unreliable transports. Evaluation criteria include asynchronous delivery, forward secrecy, post-compromise security, device lifecycle, future multi-device/group needs, mobile constraints, auditability, and long-term maintenance.

## Options to investigate
### Signal-family protocol
Evaluate an established asynchronous messaging protocol family with ratcheting. Verify exact library/runtime support, maintenance, licensing, supply-chain provenance, and the multi-device model required by Eagle.

### Noise framework
Evaluate Noise handshake patterns. Verify how session management, message-level ratcheting, asynchronous delivery, and store-and-forward would be implemented above the handshake.

### MLS (RFC 9420)
Evaluate Messaging Layer Security for future group messaging. Verify Android integration, 1:1 overhead, asynchronous delivery, implementation maturity, and operational complexity.

### Custom protocol
Treat bespoke cryptographic protocol design as exceptional-risk work. It requires strong justification, independent review, and evidence that maintained standards/libraries cannot satisfy the requirements.

## Decision criteria
- asynchronous messaging
- forward secrecy
- post-compromise security
- mobile/resource suitability
- multi-device model
- group-roadmap compatibility
- maintenance health
- supply-chain provenance
- independent auditability

## Decision
Pending review. No protocol is approved by this draft.

## Consequence
CRYPTO implementation issues must remain blocked until the accepted decision and its security review are recorded.
