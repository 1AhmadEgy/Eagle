# ADR-0008 — Cryptographic Protocol

**Status:** Proposed — Decision Pending Review  
**Date:** 2026-10-02  
**Related ADR:** ADR-0007

## Context
Evaluate an E2E protocol for asynchronous and unreliable transports against asynchronous delivery, forward secrecy, post-compromise security, device lifecycle, future multi-device/group requirements, mobile constraints, auditability, and maintenance.

## Candidate families
- Signal-family protocols: evaluate async messaging, ratcheting, runtime/library support, maintenance, licensing, and multi-device model.
- Noise framework: evaluate authenticated handshakes plus the additional session/message-ratcheting layer Eagle would need.
- MLS (RFC 9420): evaluate group messaging, Android integration, 1:1 overhead, asynchronous delivery, and implementation maturity.
- Custom protocol: exceptional-risk path requiring strong justification and independent review.

## Decision criteria
Async messaging; forward secrecy; post-compromise security; mobile suitability; multi-device model; group roadmap; maintenance; supply-chain provenance; auditability.

## Decision
Pending review. No protocol is approved by this draft.

## Constraint
Do not implement custom cryptographic protocol logic solely from this planning draft.
