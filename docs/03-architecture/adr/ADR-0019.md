# ADR-0019 — Privacy-Minimized SecurityEvent Contract

Status: Implemented in Kotlin; build verification pending
Date: 2026-10-04

## Decision

Introduce SecurityEvent as the bounded telemetry contract shared by deterministic security primitives and future statistical/ML analysis.

## Rationale

AI/ML requires versioned evidence, but telemetry itself must not become a secret-bearing interface. An explicit enum vocabulary and bounded identifiers/counters reduce privacy and resource risks.

## Security boundary

SecurityEvent is downstream evidence. It cannot authorize, bypass authentication, alter protocol state, disable rate limiting, or replace cryptographic replay/freshness checks.

## Follow-up

Implement a deterministic FeatureVector extractor from bounded event windows. Establish feature definitions, units, scaling, missing-value behavior, privacy classification, and test vectors before implementing Z-score/EWMA.
