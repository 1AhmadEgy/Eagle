# ADR-0020 — Deterministic Security Feature Extraction

Status: Implemented in Kotlin; build verification pending
Date: 2026-10-04

## Decision

Implement a bounded deterministic SecurityFeatureExtractor that converts ordered SecurityEvent windows into integer-based FeatureVector values.

## Rationale

The AI/ML boundary requires stable, auditable features before model selection. Integer scaling avoids floating-point behavior changes in the feature contract and makes test vectors portable.

## Constraints

- bounded event window: 10,000;
- explicit monotonic window;
- no silent sorting;
- explicit schema version;
- no secrets/plaintext;
- no direct policy authority.

## Follow-up

Collect representative telemetry, compare Z-score, EWMA, and Median/MAD baselines, then decide whether a heavier ML model produces material benefit.
