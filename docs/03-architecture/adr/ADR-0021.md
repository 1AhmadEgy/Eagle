# ADR-0021 — Statistical Baseline and AnomalySignal

Status: Implemented; production thresholds pending evidence
Date: 2026-10-04

## Decision

Implement lightweight deterministic Z-score, EWMA, and Median/MAD calculations before introducing heavier ML.

## Why

The current runtime has SecurityEvent and FeatureVector contracts but no representative production dataset. These methods are transparent, bounded, testable, and require no runtime ML dependency.

## Security boundary

The output is evidence only. Deterministic policy remains authoritative.

## Threshold rule

The default threshold exists only to exercise the implementation. It is not a security-approved threshold.

## Next gate

Evaluate all three methods against representative telemetry, compare alert stability and resource use, then select or combine methods through a subsequent ADR.
