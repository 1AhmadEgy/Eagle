# المعمارية — إطار مرجعي

> هذه وثيقة تأسيسية وليست ادعاءً بأن المعمارية النهائية قد حُسمت.

## طبقات التوثيق المطلوبة
1. المتطلبات ونطاق المنتج.
2. واجهات المستخدم وتجربة الاستخدام.
3. الخدمات وواجهات API.
4. طبقة البيانات والتخزين.
5. مكونات الذكاء الاصطناعي/الوكلاء إن وجدت.
6. التكاملات الخارجية.
7. الأمن والهوية والصلاحيات.
8. المراقبة والتسجيل والتدقيق.
9. CI/CD والبنية التحتية.

## قواعد التصميم
- أقل صلاحية ممكنة.
- فصل المسؤوليات.
- حدود واضحة بين الخدمات والمكونات.
- واجهات موثقة وقابلة للاختبار.
- قابلية الاستبدال للمكونات الخارجية متى كان ذلك عمليًا.
- تسجيل القرارات المعمارية في ADR.

## المطلوب قبل اعتماد المعمارية النهائية
- متطلبات وظيفية وغير وظيفية.
- مخطط سياق.
- مخطط مكونات.
- تدفقات البيانات.
- نموذج التهديدات.
- حدود الثقة.
- متطلبات الأداء والتوافر.
- خطة الاختبار والتشغيل.
