# سجل الفجوات والمخاطر المرجعية

## فجوات حالية
| ID | الفجوة | الأثر | الإجراء المطلوب | الحالة |
|---|---|---|---|---|
| GAP-001 | الأرشيفات المشار إليها غير مستخرجة حاليًا | لا يمكن إثبات اكتمال المتطلبات | استرجاع وفحص الأرشيفات | Open |
| GAP-002 | لا توجد متطلبات نهائية مثبتة في المصادر المتاحة | يمنع اعتماد تصميم نهائي | استخراج المتطلبات واعتمادها | Open |

| GAP-005 | لا توجد اختبارات CI إنتاجية متحققة حاليًا | لا يوجد دليل آلي على جودة المنتج | تثبيت build path ثم تنفيذ فئات الاختبار تدريجيًا | Open |

| GAP-007 | لا يوجد Gradle Wrapper مثبت في شجرة المستودع | البناء غير قابل للإعادة بشكل مستقل عن بيئة Gradle المضيفة | إضافة Wrapper مثبت بإصدار محدد بعد اعتماد مسار البناء | Open |

## قاعدة الإغلاق
لا تُغلق الفجوة بمجرد اقتراح حل؛ يجب تسجيل الدليل الذي يثبت تنفيذ الحل والتحقق منه.

## أولوية الأمن
الفجوات التي تمس الأسرار أو الصلاحيات أو المصادقة أو سلامة سلسلة البناء تُعامل كحواجز قبل الإنتاج، وليس كتحسينات اختيارية.
