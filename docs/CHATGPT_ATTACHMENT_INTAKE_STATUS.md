## Required metadata
Conversation/project source; uploader/member; original filename; upload timestamp; MIME/type; size; SHA-256; Git commit/blob; classification; canonical destination; security-review status; duplicate/superseded relationship.

## Rule
Do not treat an attachment as canonical solely because it was uploaded. Preserve provenance, inspect safely, classify, then promote the approved artifact into the canonical project source.
