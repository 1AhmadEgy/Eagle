# سير العمل الهندسي

## دورة التغيير
1. إنشاء Issue/متطلب واضح.
2. إنشاء فرع متخصص من main.
3. تنفيذ أصغر تغيير قابل للمراجعة.
4. إضافة/تحديث الاختبارات.
5. تشغيل الفحوصات الآلية.
6. فتح PR.
7. مراجعة الكود والأمن والوثائق.
8. معالجة الملاحظات.
9. دمج بعد استيفاء بوابات الجودة.
10. توثيق النتيجة.

## أسماء الفروع المقترحة
- docs/*
- feat/*
- fix/*
- security/*
- test/*
- infra/*

## قاعدة PR
كل PR يوضح: لماذا، ماذا تغير، المخاطر، الاختبارات، الوثائق المتأثرة، وخطة التراجع عند الحاجة.
