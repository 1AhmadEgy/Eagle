# Eagle Public Reader Guide

## للمستخدم/القارئ العام

ابدأ بميثاق المشروع ثم المعمارية ثم الأمن.

## للمطور

اقرأ lifecycle، requirements، architecture، engineering standard، testing، release.

## للمصمم

راجع product requirements، platform architecture، trust/verification states، accessibility، offline/error states.

## للمدقق الأمني

راجع security plan، threat model، crypto/storage contracts، verification register، release gate، provenance.

## كيف أعرف أن الشيء منفذ؟

ابحث عن:
REQ/ADR → source code → test → evidence → merged main

وجود وثيقة أو archive أو branch أو PR لا يثبت التنفيذ المنتج.

## كيف أعرف المرجع؟

ابحث عن:
- Approved
- Canonical
- current main
- linked ADR
- evidence

## الإبلاغ

الثغرات الحساسة تتبع SECURITY.md. المشكلات العامة تستخدم Issues مع وصف وخطوات إعادة الإنتاج والبيئة والأثر.

## الهدف

إعادة بناء فهم المشروع من مستودع عام دون الحاجة إلى قراءة المحادثات الخاصة.
